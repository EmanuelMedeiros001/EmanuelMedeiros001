<details>
<summary>⚙️ Setup — Ativar a Contribution Snake (clique para expandir)</summary>

Crie o arquivo `.github/workflows/snake.yml` no seu repositório `SEU-USUARIO/SEU-USUARIO` com o conteúdo abaixo:

<pre>
name: Generate Snake

on:
  schedule:
    - cron: "0 0 * * *"
  workflow_dispatch:
  push:
    branches:
      - main

jobs:
  generate:
    runs-on: ubuntu-latest
    steps:
      - name: Generate snake animation
        uses: Platane/snk@v3
        with:
          github_user_name: SEU-USUARIO
          outputs: |
            dist/github-contribution-grid-snake.svg
            dist/github-contribution-grid-snake-dark.svg?palette=github-dark

      - name: Push output to output branch
        uses: crazy-max/ghaction-github-pages@v4
        with:
          target_branch: output
          build_dir: dist
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
</pre>

Depois de rodar a Action pela primeira vez, o branch `output` será criado com os SVGs e a animação aparecerá automaticamente na seção acima.

</details>
