## 🧑‍💻 Sobre mim

Sou estudante de **Análise e Desenvolvimento de Sistemas no UNIPÊ**, construindo minha trajetória para me tornar Engenheiro de Software, com foco em desenvolvimento backend e arquitetura de sistemas.

Minha principal direção de estudos é **Java com Spring Boot**, com interesse em bancos de dados relacionais, APIs REST, integração entre sistemas e boas práticas de engenharia de software.

Busco compreender não apenas como implementar funcionalidades, mas também como projetar sistemas seguros, confiáveis, testáveis e preparados para evoluir.

Também exploro **Inteligência Artificial aplicada ao desenvolvimento de software**, automação de processos, RAG e integração com APIs de modelos de linguagem.

Meu objetivo é construir uma base sólida de engenharia e desenvolver soluções para problemas reais, com atenção à qualidade do código e à organização da arquitetura.
